# MATRA-X Live Demo Media

The Publish SIH Assets workflow captures the current live application and produces a 4K, 60-second evaluator demo.

Target:
https://matra-x-vision-core.base44.app/

Video master target:
- 3840x2160 UHD
- 30 fps
- H.264
- 60 seconds
- cinematic 5.1 AAC mix with centered narration

A true Dolby Atmos master requires object-based authoring and encoding with Atmos metadata. The workflow therefore uses precise 5.1 terminology rather than mislabelling the master.
