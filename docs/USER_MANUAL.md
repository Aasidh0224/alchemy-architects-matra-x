# MATRA-X User Manual

## 1. Access
Open https://matra-x-vision-core.base44.app/ in a modern browser.

## 2. Command Center
Use the Command Center as the entry point. Review material status, standardization activity, exception indicators and cross-CPSE insight.

## 3. Material Catalog
Search and inspect CPSE organization, raw code, description, category, unit, standardized mapping and verification information.

## 4. AI Standardization
Open a material and review its proposed standardized representation. Inspect the technical fields and evidence before accepting a critical mapping.

## 5. Error Detection
Inspect duplicate, mismatch, anomaly, obsolete and non-standard conditions. Open the issue detail and review the reason before taking action.

## 6. Biometric Authentication
The current prototype models face, fingerprint and iris activity. For production, use device-backed WebAuthn/passkeys and do not store raw biometric images/templates.

## 7. LIORA
Ask focused questions about SIH26099, Engineering DNA, matching, technical conflicts, errors, legacy mapping, evidence, procurement, inventory and governance.

## 8. Review
Inspect source record → inspect technical fields → inspect evidence → inspect conflict state → approve, reject or escalate.

## 9. Counterfactual workflow
Change a critical parameter such as grade, dimension, pressure class or voltage and observe how the relationship decision changes.

## 10. SIH presentation order
Command Center → Material Catalog → AI Standardization → Error Detection → Match reasoning → Conflict guard → LIORA → Cross-CPSE Insights → Event trace.

## 11. Data discipline
Always distinguish REAL, PUBLIC, SYNTHETIC, SIMULATED and DEMO information.
